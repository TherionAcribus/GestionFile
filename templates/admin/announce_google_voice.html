  1. Connectez-vous à la console Google Cloud avec votre compte Google, puis créez un projet (ou sélectionnez un projet existant dans le sélecteur en haut de page).
  2. Activez la facturation sur ce projet : Google l'exige même pour le quota gratuit mensuel de voix.
    3. {# Lien « flows/enableapi » : raccourci officiel de la documentation Google qui ouvre directement la page d'activation de l'API. #}
  3. Activez l'API Cloud Text-to-Speech (bouton « Activer »).
  4. Créez un compte de service : donnez-lui un nom (ex. « voix-annonces ») puis validez sans choisir de rôle — aucun rôle n'est requis pour Text-to-Speech.
  5. Dans la liste des comptes de service, ouvrez le compte créé, onglet « Clés » : « Ajouter une clé » → « Créer une clé » → format JSON. Le fichier .json est téléchargé sur votre ordinateur.
  6. Téléversez ce fichier via le formulaire ci-dessous.

Ce fichier donne accès à votre compte Google Cloud : conservez-le privé et ne le partagez pas.
