Nom de la pharmacie

Utilisé dans les textes grâce à la balise {P} (tickets, écrans, annonces).

{{ macros.textarea_full("pharmacy_name", pharmacy_name, "Nom affiché") }}
Numérotation des tickets
{{ macros.switch("numbering_by_activity", numbering_by_activity, "Une série de numéros par activité") }}
Activé : A-1, A-2… pour « Ordonnance », C-1, C-2… pour « Conseil ». La lettre vient de chaque activité.
Désactivé : 1, 2, 3… une seule série pour tous les patients.

La numérotation repart de 1 chaque jour. Évitez de changer ce réglage en pleine journée : la série recommencerait à 1.

Messagerie entre comptoirs
{{ macros.switch("app_messaging_enabled", app_messaging_enabled, "Activer la messagerie instantanée dans l'application comptoir") }}

Permet aux membres de l'équipe de s'envoyer des messages d'un comptoir à l'autre. Désactivée, elle disparaît immédiatement des applications comptoir et aucun nouveau message ne peut être envoyé.

Adresse du serveur sur le réseau

Sert à fabriquer les QR codes que les patients scannent avec leur téléphone. Nécessaire seulement si la borne ouvre le serveur par 127.0.0.1 (même machine) : un téléphone ne peut pas joindre cette adresse. Indiquez l'adresse du serveur vue depuis le réseau Wi-Fi, par exemple http://192.168.1.20:5000/.

{{ macros.textarea_full("network_adress", network_adress, "Adresse réseau (avec http:// et le port)") }}
Avancé : relais entre processus (RabbitMQ)

Uniquement pour une installation répartie sur plusieurs processus ou conteneurs : les messages temps réel transitent alors par RabbitMQ. La variable d'environnement RABBITMQ_URL doit être configurée. Laissez désactivé sur une installation simple.

{{ macros.switch("start_rabbitmq", start_rabbitmq, "Activer le relais RabbitMQ") }}
