{# ------------------------------------------------------------------ #} {# Librairies non critiques au rendu — chargées en fin de #} {# avec `defer`. Les scripts `defer` s'exécutent dans l'ordre du #} {# document, après l'analyse HTML et avant DOMContentLoaded ; l'ordre #} {# des dépendances est donc préservé : #} {# socket.io → utilisé par admin.js (io.connect) #} {# Sortable → utilisé par admin.js (fn `sortable()`) #} {# select2 → étend jQuery (déjà chargé en tête), utilisé admin #} {# admin.js → dépend de io / $ / Sortable / select2 / htmx #} {# ------------------------------------------------------------------ #} {# admin_macros.js : fonctions appelées par les attributs onclick/onkeypress des macros (macros.html). Elles y étaient définies EN LIGNE, dans le corps des macros : `css_unit_bloc` étant appelé 71 fois sur une page de configuration CSS, les mêmes fonctions étaient renvoyées 71 fois dans une seule réponse HTML. Le fichier ne contient que des déclarations de fonctions (aucune instruction exécutée), donc `defer` convient : elles sont définies avant toute interaction possible de l'utilisateur. #} {# admin_fragments.js : fonctions appelées par les onclick des fragments injectés par HTMX. Elles y étaient définies EN LIGNE, donc redéfinies à chaque échange. `selectImage` et `getSelectedOptions` étaient même dupliquées à l'identique dans deux gabarits chacune. #} {# Scripts spécifiques à la page (Chart.js/stats, audio, galerie…). Placés après les scripts communs : s'ils sont en `defer`, ils s'exécutent après eux ; s'ils sont inline, ils s'exécutent lors de l'analyse de ce bloc, une fois le contenu de la page déjà présent. #} {% block scripts_end %}{% endblock %}
